# ВКР 2026: Автоматизация перенаправления школьных звонков

> Выпускная квалификационная работа — 2026

## 📌 О проекте

Проект посвящён **автоматизации системы школьных звонков** на базе микроконтроллера **Arduino** с интеграцией в существующую советскую инфраструктуру школьных звонков, которая управляется обычным выключателем света.

Система позволяет **удалённо управлять расписанием и запуском звонков** через веб-интерфейс, при этом сохраняя возможность ручного управления через штатный выключатель.

## 🎯 Что я хочу получить

- Готовую систему на **Arduino**, работающую в реальных условиях школы
- Совместимость со **старой советской системой звонков**, управляемой обычным выключателем
- **Удалённое управление** через веб-интерфейс:
  - настройка расписания звонков
  - ручной запуск/остановка
  - мониторинг состояния системы
- Возможность работы **как в автоматическом, так и в ручном режиме**
